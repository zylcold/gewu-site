## 是什么

格物让你通过拍照或相册选图，用端侧 AI 快速识别物品名称与类别，帮你轻松确认数量、保质期和过期日期。名字取自「格物致知」。

## 核心功能

- **拍照识别**：拍照或选图，AI 自动识别物品名称和类别
- **Apple 智能优先**：端侧处理，照片不出设备（iOS 26+）
- **库存管理**：手动确认数量、保质期与过期日期，精准掌控
- **过期提醒**：到期自动提醒，不怕物品过期
- **位置收纳**：为物品添加位置标签，轻松找回
- **分类整理**：自定义分类与标签
- **数据本地**：所有数据存储在设备本地
- **可选 iCloud 同步**：元数据同步（用户显式开启）
- **家庭收纳共享**：多空间管理（1.0.3+）
- **本地识别模型**：可下载、可切换，支持断点续传（1.1.0+）

适用于食品、药品、化妆品、文件、证件等各类物品的日常管理。
